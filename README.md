# マイボディ - 筋トレ可視化アプリ

筋トレを記録し、部位ごとのポイントと頑張りを確認する静的 Web アプリです。記録、独自種目、色設定は Supabase に保存します。ブラウザに保存されるログイン情報が消えても、同じアカウントでログインすればデータに再びアクセスできます。

## 初期設定

このリポジトリは Supabase プロジェクトに接続済みです。下記は別のプロジェクトに接続する場合の手順です。Free プランには容量や利用条件があり、一定期間利用が少ないとプロジェクトが停止される場合があります。また、Free プランではダウンロード可能な自動バックアップが提供されないため、アプリの「設定」から定期的に JSON バックアップを作成してください。詳細は [Supabase の料金](https://supabase.com/pricing) と [運用上の注意](https://supabase.com/docs/guides/deployment/going-into-prod) を参照してください。

1. [Supabase](https://supabase.com/) で Free プロジェクトを作成します。
2. プロジェクトの SQL Editor に [supabase.sql](supabase.sql) の内容を貼り付け、実行します。これによりテーブルと、ログイン中の本人だけが自身のデータにアクセスできるルールを作成します。
3. プロジェクトの接続情報から Project URL と **Publishable key**（または従来の `anon` key）を取得し、[config.js](config.js) に設定します。これは公開用のキーです。`service_role` / secret key は設定・公開しないでください。
4. Authentication の URL Configuration で Site URL と Redirect URLs にアプリの URL を設定します。ローカル検証時は `http://localhost:8000` も登録します。メール確認を有効にしている場合、確認メールから戻るために必要です。
5. `python -m http.server 8000` で起動し、`http://localhost:8000` を開きます。新規登録して、メール確認が必要な場合は確認後にログインします。GitHub Pages でも、このリポジトリのファイル一式を配置すれば公開できます。

Supabase の設定や公開用キーについては [公式ドキュメント](https://supabase.com/docs/guides/getting-started/api-keys) を参照してください。アプリにログインするためのアカウントは Supabase 管理画面のアカウントとは別です。アプリで新規登録を行い、届いた確認メールを開いてください。認証セッションはブラウザに保持されますが、筋トレデータの保存先には使いません。

### 以前のブラウザデータの移行

以前と同じブラウザ・同じ URL でアプリを開き、ログイン後に「設定」→「このブラウザの旧データを移行」を押します。記録・独自種目・色設定を移行します。すでに存在する同じ ID の記録や種目、および保存済みの色設定は上書きされず、繰り返し実行しても記録は重複しません。移行前のブラウザデータは削除しません。異なるブラウザ、異なる URL、またはブラウザデータの消去後は、そこから旧データを読み出せません。

「データを JSON で保存」で現在のデータをダウンロードできます。「バックアップから追加」では、既存の同じ ID のデータや色設定を上書きせずに追加できます。色設定は保存先に設定がない場合のみ復元されます。これはデータを丸ごと置き換える機能ではありません。

## 頑張りの記録

- 1日1種目以上の記録がある日をトレーニング日として数えます。複数種目を登録しても1日です。
- 前日もトレーニングしていれば、その日に連日ボーナス100円を加算します。週をまたいでも連日は続きます。
- 週は月曜から日曜までです。その週のトレーニング3日目から、トレーニングする日ごとに100円を加算します。両方の条件を満たす日は両方が加算されます。
- 月曜から毎日7日間実施した場合、連日6回600円と週3日以上5回500円で合計1,100円です。過去の日付に記録を追加した場合も全履歴を再集計します。
- 今後の日付の記録は登録できません。連続日数は、今日か昨日を最終トレーニング日とする連続日数です。

## 筋トレポイント

各種目には標準の負荷を設定し、登録時にその日のきつさに合わせて変更できます。軽度は0.75倍、中度は1倍、重度は1.5倍です。目安は「余裕が大きい」「ほどよくきつい」「もう少しで限界」の3段階で、数値は厳密な運動生理学上の測定値ではなく、個人のモチベーションのための配分です。器具の重さや本人の筋力で実際の負荷が変わるため、初期値を調整して使ってください。独自種目は標準負荷を設定できます。

- 回数種目：`回数 × 負荷倍率 × 部位係数`
- 時間種目：`秒数 ÷ 3 × 負荷倍率 × 部位係数`
- 部位ごとに1時間あたり1ポイントずつ減少し、色設定の赤の基準を上限とします。
- 移行した旧記録は、従来と同じ計算になるよう中度（1倍）として扱います。

標準の色基準は0pt白、10pt青、30pt黄、60pt以上赤です。設定から変更できます。履歴を保つため、記録で使用中の独自種目は削除できません。

## テスト

`node --test tests/core.test.js` で頑張りの集計とポイント計算を検証します。Playwright と Google Chrome が利用できる場合、`node tests/browser-smoke.cjs` で保存失敗や旧データの移行などを模擬サーバーで確認できます。`npx supabase db query --linked --file tests/rls-rollback.sql` は、実際のデータベースでアクセス制御を検証し、テストデータをロールバックします。
