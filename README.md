# マイボディ - 筋トレ可視化アプリ

ブラウザだけで動く静的Webアプリです。ビルド不要です。

## 主な機能

- 人体の部位ごとにトレーニングポイントを色で可視化
- 色は 白 → 青 → 黄 → 赤 のグラデーション
- ポイントは1日90%残存の指数減衰で徐々に戻る
- トレーニング登録
  - 日付（初期値は当日）
  - 種目
  - 回数または時間
- 種目選択時に部位フィルタ・検索
- 自宅トレーニング中心の初期種目マスタ
- 腹筋ローラー、プランク、スクワットなどを標準搭載
- プランク等は「秒」、通常種目は「回」で入力
- 履歴表示
- 色基準の変更
- ユーザー独自種目の追加・編集・削除
- データは localStorage に保存

## 起動方法

`index.html` をブラウザで開くだけで動作します。

ローカルサーバーを使う場合:

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。

## GitHub Pages

リポジトリ直下に以下3ファイルをアップロードすれば公開できます。

- index.html
- styles.css

GitHub Pages の Source を対象ブランチの root に設定してください。

## ポイント計算

### 回数種目
`ポイント = 回数 × 部位係数`

### 時間種目
`ポイント = 秒数 ÷ 3 × 部位係数`

### 時間減衰
`現在ポイント = 元ポイント × 0.9^(経過時間 / 24時間)`

## 標準の色基準

- 0pt: 白
- 10pt: 青
- 30pt: 黄
- 60pt以上: 赤

設定画面から変更可能です。
